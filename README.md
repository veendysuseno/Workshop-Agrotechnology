# Modul Workshop Agrotechnology

Modul workshop yang dirancang untuk mempelajari dasar-dasar **IoT (Internet of Things)** pada bidang agrotechnology, mulai dari pengenalan pin dan pemrograman IoT MCU hingga penggunaan sensor dan integrasi data menggunakan ThingSpeak.

## 🎯 Objectives

Setelah menyelesaikan workshop ini, peserta diharapkan mampu:

1. Memahami pin yang tersedia pada **IoT MCU**.
2. Memahami dasar-dasar pemrograman **IoT MCU**.
3. Mempelajari fungsi dan penerapan **IoT MCU**.
4. Memahami cara kerja **sensor Agrotechnology**.
5. Memahami pemrograman dan penerapan teknologi **IoT**.

## 🛠️ Perangkat Lunak

Workshop ini menggunakan beberapa perangkat lunak berikut:

| No. | Software | Fungsi |
|---|---|---|
| 1 | **Arduino IDE** | Pemrograman dan konfigurasi IoT MCU |
| 2 | **ThingSpeak** | Monitoring dan visualisasi data IoT |

## 📚 Materi Workshop

Materi workshop mencakup:

- Pengenalan IoT MCU
- Pengenalan dan fungsi pin IoT MCU
- Dasar pemrograman IoT MCU
- Implementasi dan penggunaan IoT MCU
- Pengenalan sensor Agrotechnology
- Cara kerja sensor
- Pemrograman sensor menggunakan IoT MCU
- Pengiriman data sensor ke ThingSpeak
- Monitoring dan visualisasi data IoT

## 💻 Tools & Technology

- Arduino IDE
- ThingSpeak
- IoT MCU
- Agrotechnology Sensors
- Internet of Things (IoT)

## 🎓 Expected Outcome

Peserta diharapkan dapat memahami dasar penggunaan IoT MCU, menghubungkan dan membaca data dari sensor Agrotechnology, serta mengirimkan dan memantau data sensor melalui platform **ThingSpeak**.
